# DevTech IT Solutions website

## Files
- `index.html` — website content and sections
- `style.css` — responsive design and styling
- `script.js` — mobile menu and WhatsApp support-request form

## Publish with GitHub Pages
1. Upload all three files to the root of your `devtech-it-solutions` repository.
2. Make sure the home page is named exactly `index.html`.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Wait for the Pages deployment to finish and open the published URL.

## Contact details
The site is configured with the phone number and email address supplied by the owner.
